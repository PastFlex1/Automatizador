# 🚀 Extensión MetaCloser CRM para WhatsApp Web (APM Inox)

Esta extensión de Google Chrome inyecta el panel de ventas de **MetaCloser CRM** directamente sobre **WhatsApp Web**, permitiéndote gestionar prospectos, cambiar etapas del embudo y enviar cotizaciones con 1 solo clic sin salir de tu WhatsApp personal.

---

## 📌 Pasos para instalarla en Chrome / Brave / Edge (Solo toma 1 minuto):

1. **Abre tu navegador (Google Chrome, Brave o Microsoft Edge)**.
2. En la barra de direcciones escribe:
   ```text
   chrome://extensions
   ```
   *(Si usas Brave: `brave://extensions` | Si usas Edge: `edge://extensions`)*

3. En la esquina superior derecha de esa página, **activa el interruptor que dice "Modo de desarrollador"** (Developer mode).

4. Haz clic en el botón que aparece a la izquierda: **"Cargar descomprimida"** (Load unpacked).

5. Selecciona la carpeta:
   ```text
   c:\Users\Alex Palma\Desktop\metacloser-crm\extension
   ```
   *(Selecciona la carpeta `extension` completa y presiona Seleccionar carpeta).*

6. ¡Listo! Abre una pestaña con **[web.whatsapp.com](https://web.whatsapp.com)**:
   * Verás en la esquina inferior derecha el botón flotante: **`🔥 APM CRM`**.
   * Al hacer clic, se abre tu barra lateral con el cliente activo, las etapas y tu catálogo de cocinas listo para insertar con 1 clic.
